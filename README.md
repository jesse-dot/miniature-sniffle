# Riverside Academy Website

A professional website for Riverside Academy, a college-preparatory school serving students from kindergarten through 12th grade.

## About

This website showcases Riverside Academy, featuring:

- **Home Page**: Overview of the school with key statistics, news, and calls to action
- **About Page**: School history, mission, vision, values, leadership team, and accreditation
- **Academics Page**: Academic programs, departments, special programs, and achievements
- **Admissions Page**: Application process, deadlines, tuition information, and FAQs
- **Contact Page**: Contact information, interactive form, campus location, and visit options

## Features

- Responsive design that works on desktop, tablet, and mobile devices
- Professional color scheme and modern UI design
- Interactive navigation with mobile menu
- Working contact form with validation
- Smooth scrolling and animations
- Clean, semantic HTML5 structure
- Well-organized CSS with CSS variables for easy customization
- JavaScript for enhanced interactivity

## How to View

Simply open `index.html` in a web browser, or serve the directory with any web server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx http-server -p 8080
```

Then navigate to `http://localhost:8080` in your browser.
